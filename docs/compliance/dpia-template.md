# Data Protection Impact Assessment (DPIA)

Complete this before high-risk processing starts, or when it changes significantly (new data types, new processors, new countries, large-scale financial or identity data). Keep it with your compliance records.

## 1. Description of the processing
- Nature: what is collected, how, by whom, where it is stored *(see ROPA.md)*
- Scope: number of data subjects, volume, retention, geographic reach
- Context: relationship with investors, their expectations, any vulnerable groups
- Purposes and benefits

## 2. Necessity and proportionality
- Lawful basis for each purpose
- Is every data item necessary? Could less be collected?
- How are individuals informed? (privacy notice and acknowledgement)
- How are their rights supported? (Privacy & Data centre)
- Processor contracts and international transfer safeguards
